Mục lục
1. Application Scenario & Protocol Interaction
Giới thiệu bài toán Hybrid FTP (control plane TCP / data plane UDP)
Sequence diagram đầy đủ: TCP connect → USER/PASS (331→230) → lệnh điều hướng → PORT/PASV → mở UDP → truyền file (kèm ACK/timeout/retransmit) → HASH verify → QUIT
Giải thích lý do tách control/data (đúng triết lý RFC 959)
2. Project-Wide Data Structures
TCP control packet: format lệnh dạng text + bảng đầy đủ 19 mã reply code (125,150,200,220,221,226,230,250,331,350,421,425,426,450,500,501,502,530,550)
UDP custom header: bảng bit layout đủ 5 trường bắt buộc — sequence no., ACK, checksum, flags, payload length
Session management struct: client ID, trạng thái login, thư mục hiện tại, mode Active/Passive, thread/process ID
3. Functional Workflows (Flowcharts)
Flowchart: Server thread-dispatch (accept → spawn thread → xử lý độc lập từng session)
Flowchart: RDT sender state machine (send → wait ACK → timeout? → retransmit)
Flowchart: RDT receiver state machine (nhận → check checksum → check seq → ACK/duplicate)
Flowchart: Active/Passive mode toggle
4. Task Assignment Matrix
Bảng đầy đủ như Phần 2 ở trên, ghi rõ % đóng góp từng dòng
5. Self-Assessment & Peer Evaluation

Đánh giá chéo cho 2 đồng đội còn lại
Bảng % đóng góp cuối, tổng = 100%, có xác nhận của cả 3
